- **Featured Projects Gallery**: Custom bespoke UI diagrams for:

  - **LRU Cache Visualizer & Simulator** (Custom Doubly Linked List + HashMap, O(1) time complexity)
  - **StoreCraft — MERN E-Commerce Platform** (React, Redux Toolkit, Node.js, Express, MongoDB)
- **Interactive Category Filtering**: All Projects, AI, Full Stack, DSA & Algorithms.
- **"More things I've built" Repository Archive**: Secondary showcase including NutriCare AI, Sorting Visualizer, Student Management System, Payment Sprint Demo, Expense Tracker, and Quiz Management System.
- **Coding Profiles**: LeetCode (250+ solved) and GitHub verified profile integration.
- **Direct Resume Download**: Bundled PDF resume asset directly downloadable from the navbar and hero.
- **Validated Contact Form**: Client-side field validation with mailto client launcher and instant copy-email feedback.

## 💻 Local Development

### 1. Clone & Navigate
```bash
git clone https://github.com/Shivam-Agarwal-8582/webiste.git
cd webiste
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
The optimized bundle will be created in the `dist/` directory.

### 5. Preview Production Build
```bash
npm run preview
```

## 🌐 Deployment to Vercel

This portfolio is configured for zero-configuration deployment to [Vercel](https://vercel.com/):

1. Push your repository to GitHub.
2. In the Vercel Dashboard, click **Add New Project** and import the repository.
3. Vercel automatically detects the Vite framework preset:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**.
